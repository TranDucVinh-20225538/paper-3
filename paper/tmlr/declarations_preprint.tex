\section*{Data Availability}

Both datasets used in this study are publicly available. The ISIC 2018 dataset is accessible through the ISIC Archive (\url{https://challenge.isic-archive.com/data/}). The PAD-UFES-20 dataset is available at \url{https://data.mendeley.com/datasets/zr7vgbcyr2}. The submission supplement contains fixed random seeds, the power-analysis script, derived CSV inputs used for the bootstrap-interval table and Figure~\ref{fig:power}, and reproduction instructions. The original 13-row checkpoint-level output matrix required to recompute the BCa endpoints, the full set of derived result tables, the extracted representations, and the per-sample distances are archived at \url{https://doi.org/10.5281/zenodo.22130029}. The analysis code is additionally maintained at \url{https://github.com/TranDucVinh-20225538/paper-3}. Model checkpoints are available from the corresponding author on request.
