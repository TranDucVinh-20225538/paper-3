% \suppsec{<n>}{<title>} -- open supplementary section S<n> AND pin the figure
% and table counters to it, so every float inside the section is numbered S<n>.
% Heading number and float numbers are driven by the same argument and cannot
% diverge. They previously did: with plain \subsection* headings and free-running
% counters, section "S4" contained a float LaTeX numbered "S3" and section "S7"
% contained one numbered "S4", while the main text referred to the latter, by
% hardcoded string, as "Supplementary Table S7". The main text deliberately does
% not \usepackage{xr} into this file (an arXiv build of paper.tex alone would
% then render every such reference as "??"), so those strings cannot be
% link-checked by LaTeX -- which is exactly why the numbers they name have to be
% guaranteed here instead.
%
% Invariant: at most one figure and at most one table per section. A section
% needing two tables is split into two sections (see S8/S9), rather than being
% allowed to introduce a second, unnumbered float.
\newcommand{\suppsec}[2]{%
  \setcounter{figure}{#1}\addtocounter{figure}{-1}%
  \setcounter{table}{#1}\addtocounter{table}{-1}%
  \subsection*{S#1. #2}%
}

\suppsec{8}{Detectability and power of the permutation designs}

Supports main-text Section~\ref{sec:power} and the Limitations discussion in Section~\ref{sec:discussion-limitations}. Figure~\ref{fig:s8}A shows the power of each permutation design as a function of the expected Kendall's $\tau$ under the alternative, with the design's critical value $\tau_{\mathrm{crit}}$ and the pre-specified $|\tau|\geq0.3$ threshold marked; Figure~\ref{fig:s8}B shows every observed $\tau$ with its 95\% bootstrap interval against the band of values no design at this sample size can resolve. Table~\ref{tab:s8-power} gives the design-level numbers; the per-test intervals plotted in panel B are tabulated in Section~S9.
